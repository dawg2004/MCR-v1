# MCR (MY CORE RESONANCE)

Soul Atlas — Navigate the Universe of Souls

MCRは「人・データ・AI・可視化」を統合するResonance Platform。Google Earthが地球を可視化したように、Soul Atlasは人と人との関係、ネットワーク、共鳴を宇宙のように可視化する。

これは占いサイトではない。SRI(共鳴指数)は独自の象徴的スコアリングであり、科学的な相性指標ではない。

## Structure
- `src/` Next.js (App Router) + TypeScript strict + TailwindCSS
- `src/lib/engines/` 生年月日→シンボル導出エンジン(legacyから移植)
- `legacy/` MCR v0 静的ページ(Occult Engine / Fractal Identity / Surface Flow)。参照資産
- `docs/` ドキュメント、`docs/adr/` 設計判断の記録
